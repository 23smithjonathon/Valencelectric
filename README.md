# Valence

**Made for the Trades** — an AI estimating tool for electrical contractors.

Valence's signature feature, Counter Brain, works like an experienced foreman: describe a job in plain language, and it talks you through it, asks the right questions, catches what you missed, and builds a complete, priced material and labor list using your brands, rates, and margins. The goal is to order the right materials the first time — no wrong-wire returns, no wasted trips.

## Live site
- Website: https://valencelectric.org

## Branch strategy
- main — live/production. Protected. Never edited directly.
- develop — shared workspace where features combine and get tested.
- feature/... fix/... chore/... — one branch per task, created off develop.

All changes go through a Pull Request and require 1 review before merging.
